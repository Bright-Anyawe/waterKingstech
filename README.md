# WaterKingsTech Website

The marketing and catalog site for **WaterKingsTech**, a phone, laptop, accessories and repairs shop at Circle Mall, Tip Toe Lane (Blue Gate, Gate 2 Exit), Accra.

The site is built to take visitors from **search → product or service → WhatsApp, call or directions**. It has no cart, checkout or accounts. Every "Buy" button opens WhatsApp with a message already written.

## Stack

- Next.js 16 (App Router), React 19, TypeScript
- Tailwind CSS v4 (design tokens live in `app/globals.css`)
- Motion for animations, loaded lazily and respecting `prefers-reduced-motion`
- Lucide icons and `next/image`

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000. Other commands: `npm run build`, `npm start`, `npm run lint`.

## Editing content

All content lives in `/data`, so you rarely need to touch the components.

| File | What it controls |
| --- | --- |
| `data/contact.ts` | Phone, WhatsApp numbers (the first is used by all WhatsApp buttons), email, social links |
| `data/hero.ts` | Hero background video and its poster frame (files in `public/videos`) |
| `data/business.ts` | Address, map, opening hours, shop photos, description |
| `data/products.ts` | Product catalog (name, variant, specs, price, stock, image, featured) |
| `data/categories.ts` | Catalog categories and sub-categories |
| `data/repairs.ts` | Repair and diagnostic services (optional turnaround time) |
| `data/programs.ts` | Installment plan details and referral commissions |
| `data/testimonials.ts` | Customer reviews |
| `data/navigation.ts` | Header links |

- **Prices:** set `price` in cedis (for example `12500`). `null` shows "Price on request".
- **Stock:** set `availability` to `in-stock`, `limited-stock`, `out-of-stock` or `on-request`.
- **Featured products:** add `featured: true` and a short `highlight`.
- **Real photos:** put files in `public/images/...` and use for example `src: "/images/products/iphone-15-pro.jpg"`.

A value of `null` means "not supplied yet". The site shows a dashed amber placeholder for it, so nothing unconfirmed is ever presented as real.

## Deployment (Vercel)

1. Import this GitHub repository in Vercel. It detects Next.js automatically.
2. Add the environment variable `NEXT_PUBLIC_SITE_URL` with the live domain (for example `https://waterkingstech.com`). Canonical URLs, the sitemap, `robots.txt` and Open Graph tags use it.
3. Deploy.

## SEO

- Metadata, Open Graph and Twitter cards are set in `app/layout.tsx`. The social share image is generated by `app/opengraph-image.tsx`.
- `app/sitemap.ts` and `app/robots.ts` generate `/sitemap.xml` and `/robots.txt`.
- An `ElectronicsStore` JSON-LD block is built from `/data` in `lib/structured-data.ts`. It includes the address, phone and hours automatically once they are filled in.
